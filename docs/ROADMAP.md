# Roadmap 路线图

> 原则不变：**确定性引擎是成片依据，AI 只做建议层；重活交给专业软件，不自研 3D 引擎。**

## P0 · 引擎基础（已完成）

- 切点 / BPM / 踩点率分析，长视频自适应采样
- 两种一键模式（复刻剪辑 / 踩点成片）+ 质量评分
- 音乐轨道编辑（重复 / 变速 / 音量 / 淡入淡出 / 循环），预览导出同口径
- 参考音床、逐槽色彩匹配、7 项卡点效果
- 浏览器内 1080p 导出、IndexedDB/OPFS 本地项目库
- 可选 AI 导演（任意 OpenAI 兼容 API + VLM 打标）

## P1 · 质量上限

### 1. AI 真正理解素材并复刻

- 逐镜头多帧采样 → 语义标签（主体 / 动作 / 景别 / 运镜 / 情绪 / 是否对白）+ 视觉嵌入向量；
- 选材打分从「色调最近」升级为「语义 + 色调 + 景别 + 运镜连续」联合评分，AI 导演给出可核验理由；
- 建立「与参考片逐镜头对齐」的评测集，量化风格相似度，避免靠肉眼验收；
- 依赖：可插拔视觉模型（OpenAI 兼容 vision 或本地模型），Key 由用户提供。

### 2. 可插拔素材源协议

- 统一「本地文件 / URL / 生成模型（ComfyUI / SD）/ 素材库 API」的选源接口 `GenerationProvider`，
  产出片段进入同一素材索引，让 AI 可以跨源挑素材。

### 3. 专业软件桥接（3D / 合成的正确姿势）

把 CPvidego 当作**编排层**，重活交给专业软件：

- 本地 MCP 桥：向 Premiere / After Effects / DaVinci Resolve / Blender 下发时间线、素材引用与参数，由这些软件完成 3D 场景、合成与渲染；
- 交换格式：EDL / FCPXML / OTIO，保证可逆交接；
- 站内只做轻量 2.5D 补偿（视差分层、Ken Burns 相机运动）作为过渡。

**明确不做**：自研 3D 场景编辑器、渲染农场、云端转码服务。

## P2 · 编辑体验

- 时间线增删 / 重排 / 改时长，playhead 拖拽与吸附；
- 关键帧与速度曲线、转场与文字层；
- 9:16 / 1:1 画幅与 4K / HDR 导出、导出队列；
- 全库增量语义标注、示例工程与离线兜底。
